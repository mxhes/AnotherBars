# AnotherBars

Blizzard's action bars in the look of the "Another" UI suite (AnotherLedger,
AnotherHUD) for WoW Forever: Action Bars 1-8, the Stance bar, the Pet bar and
a totem bar, with tighter spacing, Blizzard's bar artwork hidden and settings
in Blizzard's Edit Mode.

In development: nothing to play with yet. The design is in
`docs/superpowers/specs/`.
